# Grid

<ComponentLinkRow
  docsHref="219dd1-grid"

`<Grid>` er en layout primitive: den implementerer grid layout for alle brekkpunkter. Grid i Figma defineres som stiler og er dermed ikke egen komponent.

Les mer om brekkepunkter, grid tokens og hvordan vi bruker det hele i [Grid og layout (design.domstol.no)](https://design.domstol.no/987b33f71/p/442cff-grid-og-layout/b/312b16).
