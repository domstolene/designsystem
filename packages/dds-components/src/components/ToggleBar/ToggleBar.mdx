# ToggleBar

ToggleBar er en rad med semantiske radioknapper. Den består av følgende subkomponenter:

- **`<ToggleBar>`** - wrapper for barna.
- **`<ToggleRadio>`** - elementer å velge mellom.

## Kontrollert

<Source
  code={`
  import { ToggleBar, ToggleRadio Button } from '@norges-domstoler/dds-components';

const [checked, setValue] = useState('Alt1');

  <ToggleBar
    checked={checked}
    onChange={(_event, value) => {
      setValue(value);
    }}
  >
    <ToggleRadio label="Alt1" value="Alt1" />
    <ToggleRadio label="Alt2" value="Alt2" />
</ToggleBar>
`} />

## Bredde

Bredden på alle `<ToggleRadio>` i en `<ToggleBar>` skal være den samme. `<ToggleBar>` tar i utgangspunktet hele tilgjengelige bredden og fordeler den likt mellom barna. Spesifikk bredde kan settes enten i `<ToggleBar>` eller i selvutviklede wrapperen til `<ToggleBar>`.
