## Bruk som lenke

### Vanlig

Bruk `as` prop slik at komponenten kan returnere vanlig lenke.

<Source code={`

<Button as='a' href="/saker">
  Mine saker
</Button>
`} />

### Klient-side ruting

Bruk `as` prop slik at komponenten kan returnere lenke fra rammeverket du bruker.

#### `react-router`

<Source code={`
import { Link } from "react-router";

<Button as={Link} to="/saker">
  Mine saker
</Button>
`} />

#### `Next.js`

<Source code={`
import NextLink from 'next/link';

<Button as={NextLink} href="/saker">
  Mine saker
</Button>
`} />

## Retningslinjer

### Deaktiverte knapper

Unngå å bruke `disabled`-attributtet da det fører til [dårlig brukeropplevelse](https://axesslab.com/disabled-buttons-suck/).
Brukeren får ofte ikke tilstrekkelig informasjon om hvorfor handlingen ikke er tilgjengelig, og det kan føre til frustrasjon.
Deaktiverte knapper er typisk "grået ut" med lav kontrast, noe som gjør de vanskelig å lese.
Samtidig vil høy kontrast indikere at knappen er aktiv, og dermed føre til mer forvirring.

#### Alternative løsninger

Avhengig av kontekst anbefaler vi ulike alternative løsninger:

- **Skjema:** Dersom brukeren ikke kan gå videre eller sende inn skjema, vis en tydelig feilmelding som forklarer hvorfor.
- **Irrelevant handling:** Dersom handlingen ikke er relevant i den aktuelle konteksten, vurder å skjule knappen helt. Informer brukeren om hvorfor handlingen ikke er tilgjengelig.

#### Unntak

Unntaket er når knappen laster; `disabled`-attributtet er nødvendig for å unngå dobbel handling. Dette er innebygd når du bruker `loading`-prop.
