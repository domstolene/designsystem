# Chip

Chip er en paraply for komponenter som representerer ulike typer interaktive merkelapper.
Komponentene eksponeres som både compound og ikke-compound.

Følgende komponenter distribueres:

- **`<ChipCheckbox>`** som `<input type="checkbox">`
- **`<ChipRadio>`** som `<input type="radio">`
- **`<ChipButton>`** som `<button>`
- **`<ChipRemovable>`** som `<div>` med `<button>` for lukking
- **`<ChipGroup>`** som `<div>` med `role="group"` og valgfri ledetekst for gruppering
