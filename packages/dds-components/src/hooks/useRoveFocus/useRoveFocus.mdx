Bytter fokus mellom elementer i en gruppe med piltaster og ikke Tab, og looper fokus i gruppen.

## Skjermleser

Skjermlesere skiller mellom "browse mode" og "focus mode" som påvirker hvordan piltaster brukes.
I "browse mode" navigerer piltastene gjennom innholdet på siden, mens i "focus mode" er de tilgjengelige for navigering.
For å kunne bruke piltastnavigering med `useRoveFocus`, må skjermleseren være i "focus mode".
Dette oppnår vi ved å bruke riktige ARIA-roller for containeren og de fokuserbare elementene.

## Bruk

<Source
  code={`
 import { useRoveFocus } from '@norges-domstoler/dds-components';
 import elements from './elements';
 import RoveItem from './RoveItem';

function MyComponent() {
const [focusedIndex, setFocus] = useRoveFocus(elements.length);

return (

<ul role="menu">
  {elements.map((element, index) => (
    <li key={element}>
      <RoveItem
        role="menuitem"
        index={index}
        shouldFocus={focusedIndex === index}
        setFocus={setFocus}
      >
        {element.name}
      </RoveItem>
    </li>
  ))}
</ul>
) }; `} />
