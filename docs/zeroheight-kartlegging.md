# Innhold å gå gjennom fra design.domstol.no

Kartleggingen tar utgangspunkt i 198 sideoppføringer i den offentlige Zeroheight-navigasjonen, inkludert forsiden. Lenker går til den aktuelle siden eller fanen. Tekst, figurer, Figma-blokker, eksempler og vedlegg må vurderes sammen når dere avgjør hva som skal overføres.

- **Mangler**: Ingen tilsvarende dokumentasjonskilde funnet i repoet.
- **Delvis**: Repoet dekker deler, for eksempel komponentens API eller en pakkeendring. Tabellen peker til det som bør sammenlignes før overføring.
- **Avklar**: Oppføringen er funnet i navigasjonen, men innholdet eller skillet mot repoet er ikke verifisert i detalj. Denne statusen gjelder særlig innebygde eksempler, bilder og vedlegg; listen er ikke et komplett vedleggsregister.
